# 🕹️ Pong Game in Python

A simple recreation of the **classic Pong game** built using Python’s `turtle` graphics module.
This project demonstrates **Object-Oriented Programming (OOP)** principles, event handling, and basic game logic — great for beginners learning Python game development.

---

## 🎮 Game Overview

Pong is one of the earliest arcade video games. The objective is simple:
Use paddles to bounce the ball back and forth — miss it, and your opponent scores a point!

This project includes:
✅ Two-player paddle control
✅ Ball movement and realistic bounce physics
✅ Score tracking and display
✅ Game over screen when a player wins

---

## 🧠 Concepts & Skills Learned

* Object-Oriented Programming (Classes, Inheritance, Encapsulation)
* Collision detection and boundary handling
* Event-driven programming with `onkey()`
* Game loop control using `time.sleep()` and screen updates

---

## 🎮 Controls

| Player   | Move Up | Move Down |
| -------- | ------- | --------- |
| Player 1 | `W`     | `S`       |
| Player 2 | `↑`     | `↓`       |

---

## 🏁 Game End Condition

The game ends when one player reaches a score of **10 points**, and “Game Over” is displayed on the screen.
